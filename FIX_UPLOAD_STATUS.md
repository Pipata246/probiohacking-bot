## Что было сделано

### 1. 🔧 Исправлена очистка имен файлов (public/app.js)
**Проблема:** Имена файлов с русскими символами и спецсимволами вызывали ошибку 400 в Supabase Storage.

**Решение:** Добавлена функция `sanitizeFileName()`:
```javascript
function sanitizeFileName(name) {
  return name
    .replace(/[^a-zA-Z0-9._\-\s]/g, '_') // Спецсимволы → подчеркивание
    .replace(/\s+/g, '_')                  // Пробелы → подчеркивание
    .replace(/_+/g, '_')                   // Множественные _ → один _
    .toLowerCase();                        // Нижний регистр
}
```

**Пример:**
- До: `Тареев_М_В__2176345901_(ГЕМАТОЛОГИЯ).pdf`
- После: `tareev_m_v__2176345901_gematologiya.pdf`

1. **api/analysis-photos.js** - раскомментировать блок:
```javascript
try {

  // ...
}
```

2. **api/chat.js** - раскомментировать:
```javascript
if (diagnosticData && diagnosticData.analysis_photos...) {
  diagnosticData = await processAnalysisPhotosWithKimi(...);
}
```

3. Убедиться что `KIMI_API_KEY` в `.env` верный
