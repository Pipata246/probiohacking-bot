Архитектура:
────────────
1. POST /api/analysis-photos (загрузка)
   ↓
   Kimi анализирует → получает description
   ↓
   Сохраняет в БД (description = "...")
   ↓
   Пользователь видит готовое описание

2. POST /api/chat (запрос)
   ↓
   Проверяет: есть ли description?
   ├─ ✅ ЕСТЬ → берет из БД
   └─ ❌ НЕ ЕСТЬ → Kimi анализирует параллельно
   ↓
   DeepSeek получает prompt с description
   ↓
   Дает ответ с учетом анализов
   ↓
   Description сохраняется в БД (в фоне)

⚠️ ВАЖНЫЕ МОМЕНТЫ:
