🔍 КАК РАБОТАЕТ:

Архитектура:
────────────
1. POST /api/analysis-photos (загрузка)
   ↓
   Kimi Vision анализирует фото → получает description
   ↓
   Сохраняет в БД (description = "Анализ крови: RBC...")
   ↓
   Пользователь видит описание

2. POST /api/chat (запрос)
   ↓
   Проверяет: есть ли description в БД?
   ├─ ✅ ЕСТЬ → берет из БД (очень быстро)
   └─ ❌ НЕТ → Kimi Vision анализирует параллельно
   ↓
   DeepSeek получает prompt с description
   ↓
   Дает ответ с учетом анализов
   ↓
   Description сохраняется в БД
